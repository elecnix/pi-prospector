Problem prospect nodes --as-of shows one generation per output key; prospect show --session --as-of blends every superseded generation — the same flag, decided by which query function the command happened to call.

Solution Deepen current-generation.ts from "the supersession predicate" into "what is visible at T", covering retraction and supersession together, and compose it into every as-of read.

• locality: eight paste sites become one

• fixes the flag inconsistency for free

• one predicate to test, not five variants

• retraction stays reversible, as DESIGN.md requires

Smallest candidate here, and the one that touches a stated invariant. Confirm at runtime against a revised graph before changing which shape is correct — then make it consistent deliberately.

Problem AGENTS.md puts all SQL in src/db/, yet the plan context hands analyzers a raw db handle and ten of them write their own SELECT — while 22 others smuggle their whole computation across plan→analyze through an untyped unit.meta.

Solution Replace the handle with named session-read accessors, and give each analyzer a typed plan payload so the interface can describe what actually crosses it.

• test surface: analyze() without running detection

Name the legitimate corpus-wide reads first (contrast siblings, lexicon reference, similarity clusters). Narrowing before they are named will look like breakage.

Top recommendation

One operation catalogue behind the tool and the slash commands

It has the clearest evidence of cost — the second-hottest file in the repo is a duplicate surface, not hard work — it touches no invariant, and it converts the largest existing test file's fake-host harness into an interface the tests can call directly. Delete the duplication and the churn stops; that is the whole bet.

If correctness outranks refactor today, do the as-of predicate first instead: it is the smallest candidate here, and it makes a stated invariant true rather than tidying anything.
